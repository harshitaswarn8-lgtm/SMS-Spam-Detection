# SMS Spam Detection Using Machine Learning

## Project Overview
This project predicts whether an SMS message is Spam or Ham (a normal message) using machine learning algorithms.

## Dataset
The project uses a labelled SMS dataset containing spam and normal messages.

## Algorithms Used
- Multinomial Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

## Technologies Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Matplotlib

## Project Workflow
1. Load the dataset.
2. Clean and preprocess the data.
3. Convert text into numerical features using TF-IDF.
4. Train five machine learning algorithms.
5. Compare model performance.
6. Predict whether a new SMS is spam or normal.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## How to Run
Open the notebook in Google Colab and run the cells in order.
